🛠️ Getting Started
To view this project and explore our analysis:

📄 Open the Report
→ Click on congestion.html to see the full rendered analysis in your browser.


📺 Watch the Final Video Presentation
→ View on Google Drive


You can stream the video directly

Or click the Download button in the top right corner to save it locally


📁 Access the Full Dataset (optional)
→ Download CSV from Google Drive
Note: Due to GitHub file limits, the full dataset is hosted externally. A 50K-row sample is included in this repo.


🔄 Reproduce the Analysis Locally (Optional)
If you'd like to run the code yourself:

Download or clone this repo

Open congestion.qmd in RStudio

Ensure the dataset file is placed in data/

Click Render in RStudio to regenerate congestion.html
